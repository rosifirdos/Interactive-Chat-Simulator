# 🎮 Interactive Chat Simulator

Sebuah proyek Python interaktif berbasis teks yang menyimulasikan percakapan seperti chat di aplikasi pesan. Pemain bisa memilih respons yang berbeda dan melihat bagaimana alur cerita berkembang berdasarkan pilihan yang diambil.

## ✨ Fitur Utama

* 🌱 Alur cerita bercabang dengan berbagai ending
* 📚 Struktur data menggunakan tree berbasis dictionary
* 👥 Karakter interaktif: Dennis & Devi
* 🧠 Cocok untuk proyek logika, storytelling, atau simulasi percakapan

## 🚀 Cara Menjalankan

1. Pastikan kamu sudah menginstal Python (versi 3.6+)
2. Jalankan file Python:

```bash
python chating.py
```

## 🗂 Struktur Proyek

## 🔧 Penggunaan

Setelah program dijalankan, kamu akan melihat dialog interaktif di terminal. Pilih opsi dengan mengetik angka sesuai pilihan untuk melanjutkan percakapan dan melihat ke mana alur cerita akan membawamu.

## 💡 Tujuan Proyek

Proyek ini dibuat sebagai latihan logika pemrograman, simulasi percakapan, dan eksplorasi alur cerita bercabang. Sangat cocok untuk:

* Mahasiswa atau pelajar yang ingin belajar tentang struktur data tree
* Penggemar narasi interaktif dan storytelling
* Eksperimen ide game berbasis teks
